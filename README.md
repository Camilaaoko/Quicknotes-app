# QuickNotes App

QuickNotes is a lightweight web application designed to help users quickly capture, organize, and search personal notes with persistence and category-based visual styling.

## Features
- **Add Notes**: Create notes with custom text and distinct categories (Personal, Work, Study).
- **Validation**: Enforces non-empty entries and limits note length to 200 characters with real-time error messages.
- **Search**: Dynamically filter notes by search terms without page reloads.
- **Persistence**: Retains notes across browser sessions using LocalStorage.
- **Responsive Layout**: Adjusts form layout seamlessly on mobile screens.
